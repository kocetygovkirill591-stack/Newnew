НОВАЯ ЖИЗНЬ 2.0 — ГОТОВЫЙ ПРОЕКТ

1. Распакуй этот ZIP.
2. В репозитории GitHub Newlife7 открой Add file → Upload files.
3. Загрузи ВСЁ содержимое этой папки в корень репозитория, включая .github и app.
4. Нажми Commit changes.
5. Открой вкладку Actions.
6. Открой workflow "Build Android APK" и дождись зелёной галочки.
7. Открой успешный запуск workflow → внизу Artifacts → NovayaZhizn-APK.
8. Скачай ZIP из Artifacts, распакуй его и получишь NovayaZhizn.apk.
9. Перед установкой APK на телефоне Android может попросить разрешить установку из этого источника.

WEB-ВЕРСИЯ:
Папка web-demo содержит браузерную демо-версию. Workflow "Publish web demo" публикует её через GitHub Pages.

ВАЖНО:
GitHub не распаковывает загруженный ZIP. Загружать нужно содержимое распакованной папки, а не сам ZIP.
