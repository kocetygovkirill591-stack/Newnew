# ❤️ Новая жизнь 2.0

Мобильная life-sim игра для Android.

## В игре
- создание персонажа: имя, возраст, пол и город;
- 5 городов: Москва, Санкт-Петербург, Казань, Сочи, Новосибирск;
- работа и карьерная лестница;
- развитие навыков и повышение дохода;
- деньги, покупки, жильё и транспорт;
- отношения, свидания и семья;
- бизнес и пассивный доход;
- ежедневные действия и случайные события;
- сохранение прогресса на устройстве.

## Сборка APK
GitHub Actions автоматически собирает debug APK после push в `main`.
Готовый файл находится в Actions → успешный запуск → Artifacts → `NovayaZhizn-APK`.

## Браузерная версия
`web-demo/` — отдельная HTML/CSS/JS версия для GitHub Pages.
